## 2. Key conclusions: already fixed vs genuine missing surface

**Already fixed/protected in 0.4.4:** nearest-`.git` fallback protection; Node/Rust contract-v1 native receipt parsing, missing-profile non-PASS; restricted direct-tool mechanical stage; first-turn role lock; trusted signal transport; bounded Implementation no-native-progress and Validation terminalization attempts; non-bypassable family escalation report; atomic seat capacity and reservation cleanup. Re-test but *do not duplicate* these repairs.

**CODE-CONFIRMED missing source contract (not proof of 2026-11-04 incident root cause):**
1. Thread-success evidence is not required to match current source SHA and *every* assigned gate prerequisite, including required live preview. Neither an old `exec-*` success nor green focused tests can establish a current operational listener.
2. Native LVO has no explicit authorized nested-target identity contract separate from process/turn CWD. The existing safe nearest-root behavior can select an unintended same-project checkout.
3. Persisted workflow snapshot lacks task prerequisite/progress digest; existing watchdog measures some native activity rather than new admissible evidence.
4. Non-source operations/benchmark task is not modelled as a bounded task kind. Existing roles cannot be widened automatically.
5. Terminalization prompt/allowed-tools mismatch is present; source asks for a missing test while the protected turn forbids tools other than signal.
6. Terminalization request forces `tool_choice=required` without proven backend-specific capability guard. This is **conditional P1**, pending actual provider evidence, not blanket provider migration.

**Not confirmed defects:** 8/8 spawn failures (limits may be intentional or already full), Repair Worker missing Implementation-only native runner (expected), malformed first-turn TOML header (expected rejection), and any exact production-runtime attribution without the installed executable identity. No changes to agent resources, identities, security policy or live project trees are authorized by triage alone.
